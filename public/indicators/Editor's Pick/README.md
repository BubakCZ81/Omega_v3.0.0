# Editor's Pick

TradingView's Editor's Picks is a mixed feed, not a technical-category tree. These local subcategories are Omega's technical groupings.

Only scripts with an explicit redistribution license and a PineTS-verified local source are included. The included scripts declare GPL-3.0 in their source headers; the full license is at `../everget/LICENSE`. Each subcategory's `catalog.json` records the local source, TradingView page, and license.

As of 2026-10-22, the verified licensed picks are:

- **Trend:** Linear Regression (All Data)
- **Trailing Stops:** Nick Rypock Trailing Reverse (NRTR)

Other Editor's Picks are not copied unless their source explicitly permits redistribution and they pass the installed PineTS runtime.
